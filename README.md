# Muhammad Sahal — Personal Portfolio

A responsive personal portfolio website for **Muhammad Sahal**, a full-stack developer based in Bangalore, India. It presents selected projects, technical skills, experience, education, certifications, and contact details in a modern, motion-rich interface.

## Highlights

- Responsive portfolio layout with light and dark themes
- English and Turkish language support
- Project case studies and technology stacks
- Interactive sections for experience, skills, education, and certifications
- Smooth scrolling and animated UI elements
- Downloadable resume and direct contact links

## Built With

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- next-themes and Lenis

## Getting Started

### Prerequisites

- Node.js 20 or later
- npm

### Installation

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Commands

```bash
npm run dev     # Start the development server
npm run build   # Create a production build
npm run start   # Run the production server
npm run lint    # Run ESLint
```
